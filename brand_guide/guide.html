02 · 符号制图 CONSTRUCTION
纯图形符号 — 川 · 标点  PRIMARY SYMBOL
方是器，是格局；S 是川流，是周期，是阴阳的分界；上下两粒标点，是句读，是潮汐的起点与终点。全部比例基于模数 M（M = 水线笔宽），不得更改。
模数  MODULE
水线笔宽 = M
标点直径 = M
标点圆心 = 端点
端距（上下）= 2.4M
水线居中 = 6M 轴
净空  CLEAR SPACE
符号四周必须保留的最小净空，确保识别与呼吸感。
MIN. CLEAR SPACE
= 3M（四边）
最小尺寸  MINIMUM SIZE
为保证水线与标点可辨，符号不得小于最小尺寸使用。
MINIMUM WIDTH
16px / 6mm（16px 仅限 favicon）
色调  TONES
墨底为正。朱砂仅在水线作"阴"之语义时使用，不作装饰。
墨底白川（正） · 纸底墨川（反）

03 · 尺度与组合 SCALE & LOCKUP
尺寸系列  SIZE SCALE
同一符号，自 favicon 至封面，一律矢量缩放，不做任何二次绘制。常用调用尺寸如下。
16 24 32 48 64 96 128 单位 px · 另有 256 / 512 / 1024 导出
组合标志  PRIMARY LOCKUP
符号与 trading-lab 字标的固定组合，用于页眉与落款。字标一律小写等宽体，间距与比例不得更改。
符号 : 间距 : 字标基线 — 9M · 3M · 与符号中线对齐
调用场景  USAGE
符号出现的全部位置——此外不再新增。
16px — favicon / 浏览器标签
22px — 页眉组合标志（每日所见）
110px — 首页封面·观水
256px+ — 印刷与物料
矢 量 — SVG 为唯一母版，PNG 仅作导出
隐藏记号  HIDDEN MARK
符号不作解释。水归器内，各观方圆——长期使用的人自会发现。
误用  MISUSE
以下用法一概禁止——符号只以母版的原样出现。
禁止拉伸变形
禁止旋转倾斜
禁止随意配色
禁止圆角与投影
禁止添加文字元素

04 · 印章 THE SEAL
朱砂方章 — 小篆 HSN  THE CINNABAR SEAL
字形出自 HSN 指定之篆意手稿：收笔尖细、中段饱满，如篆刻之冲刀；H、N 立柱带撇捺之意，S 上下内旋、遥相呼应。朱砂白文，只以印章的方式出现——盖上去，而非画上去。
笔法  STROKES
起收 = 尖锋，如冲刀
行笔 = 中段饱满
字高 = 62（29–91）
字宽 = 92 · 左右边距 14
S = 上下内旋，遥相呼应
色调  TONES
朱砂白文为正章；墨底白文为辅；纸底墨文为日常引用。毛边与裂痕只存于手稿，用章一律取其净形。
朱砂（正） · 墨（辅） · 纸（引）
最小尺寸  MINIMUM SIZE
篆意收笔在过小时会糊作一团，印章不得小于以下尺寸。
MINIMUM WIDTH
24px / 8mm
用印之位  PLACEMENT
印章只落在三处，如同落款——此外不用。
终 幕 — 首页收束，暖米白之上
页 脚 — 每页落款，与 HSN 同行
签 名 — 每篇文章之末，配研究编号
№ 001 — 006 · HSN / RESEARCH

05 · 色彩与戒律 COLOR & DISCIPLINE
色彩  CHROMATIC ORDER
颜色即语义，而非装饰——墨为阳，水为阴，朱砂为转换与警讯，暖米白只出现在品牌的终幕。

戒律  DISCIPLINE
一 · 朱砂不作按钮、不作链接、不作大面积底色
二 · 水蓝仅用于「阴」之语义，不作装饰
三 · 符号与印章不得旋转、拉伸、描边、投影
四 · 不得更改模数比例与字距
五 · 渐变、玻璃拟态、圆角卡片，一概不用
六 · K 线、涨跌箭头、金币、火箭，永不出现
母版与导出  MASTER & EXPORTS
母版 — SVG 矢量，120 × 120 网格
符号导出 — 16 / 24 / 32 / 48 / 64 / 96 / 128 / 256 / 512 / 1024 px
印章导出 — 24 / 32 / 48 / 64 / 96 / 128 / 256 / 512 / 1024 px
组合标志 — 240 / 480 / 960 px 宽
色调 — 墨底 · 朱砂底 · 纸底，各尺寸齐备
观察变化，而非预测未来。
