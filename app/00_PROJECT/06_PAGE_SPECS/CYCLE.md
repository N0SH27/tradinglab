# PAGE SPEC · 周期 CYCLE（#/cycle）

**Purpose**：知道自己站在圆环的哪一段——"重要的不是预测拐点"。
**User Question**：各行业现在处于周期哪个阶段？当前市场状态下哪面权重最高？
**Primary KPI**：读者在七阶段条上找到自己的行业，并理解"空着的阶段同样是一种信息"。

## Content Hierarchy

1. PageHead（06 / 周期 / CYCLE）+ 太极意象的抽象方块图（禁用太极图实物）
   +「盛极而衰，否极泰来。」
2. 七阶段位置条（增长→狂热→分化→出清→重构→新周期，行业归入各阶段，空栏显"— 空 —"）
3. 三层判断（层级/角色/问题清单）
4. 题材的生命（THEME_LIFECYCLE，阶段名统一 water 深水蓝）+ 题材级别（政策＞行业事件＞消息）
5. 四面权重表（FACE_WEIGHTS：每行最高权重 = 墨色加粗，非彩色）

## Components

SectionHead、Label、网格卡片阵。

## Interaction

纯静态阅读页；表格可横滚。

## Data

CYCLE_STAGES / CYCLE_INDUSTRIES / THEME_LIFECYCLE / THEME_LEVELS / FACE_WEIGHTS。

## Forbidden

❌ 权重最高值用朱砂（2026-08-15 已收敛为墨色加粗——数据强调用字重不用色）；
❌ 加实时周期信号或行情联动；
❌ 太极图。
