# 01 · PROJECT SPEC — trading-lab

> **我们到底在做什么？**
> P0 级文档。与聊天记录冲突时，以本文件为准。

---

## 项目定位

trading-lab 是 HSN 的个人交易研究实验室网站。它把私人的、易逝的投资认知
（世界观、系统、命题、修正记录）变成**公开的、可追溯的、持续更新的档案**。

不是内容发布工具，而是认知的外化装置：
- "所有内容都是活着的档案，而非一次性结论。"
- "沉默地改观点，是研究的死亡。"

核心张力：多数投资内容追求"预测正确的形象"，本站追求**观察变化的诚实**——
修正记录比正确预测更值得展示。

## 产品愿景

不是"一个比较好看的投资 Dashboard"，而是逐渐形成：
**一套有自己认知框架的投资研究操作系统。**

## 核心用户

1. **HSN 本人**（首要）——网站是强制自己把思考成文、把修正留痕的纪律装置。
   档案的读者首先是未来的作者。
2. **同频的深度阅读者**（次要）——愿意读 10 分钟长文、理解"虽然……但是……"
   结构、关心"概率如何随证据修正"而非"买哪只票"的人。

无获客/转化目标；读者质量优先于数量。[AI 推测：用户规模不是指标。]

## 核心价值

向读者提供一个**思考的框架样本**——看别人如何组织不确定性：
- 命题的结构（矛盾/证据/反证/概率/窗口/证伪信号），而非观点本身；
- 修正痕迹（日期、方向、原因）；
- 产业关系与时代坐标，而非个股名单；
- 可检验、可复用、可推翻的方法论。

## 产品哲学

1. 观察变化，而非预测未来。（首页主标题）
2. 阴阳世界观：阳 = 看得见的增长与叙事；阴 = 看不见的约束与出清。
3. 反者道之动：所有趋势的尽头都是反转，柔弱的信号比强硬的信号更可靠。
4. 不操作是持仓：无为、空仓、等待是系统的组成部分。
5. 做赌场不做赌徒：玩的不是行情，是统计。
6. Build once, systematize everything：一切沉淀为可复用结构；先减重，再进化。

## 品牌人格

克制、诚实、有耐心、知行合一的研究者人格——一间书房，不是一个媒体。
- 印章必须用手稿，不用程序生成；
- 短句、断言式、不讨好（"没有系统支撑的重仓，不叫勇气，叫扶贫"）；
- 对错误坦然；
- 对审美反馈直接且坚决，被否决的方向不回头。
[AI 推测：人格的反面是"专家人设"——不扮演权威，展示过程。]

## 内容承载边界（用户裁决）

**网站只承载思想，不承载操作。**
败者模式预警、5P 选股等操作类清单留在 Notion 当工具——除非用户明确要求。

## AI 工作原则（上下文优先级）

```text
P0  01_PROJECT_SPEC.md        最高优先级
P1  02_DESIGN_CONSTITUTION.md
P2  03_INFORMATION_ARCHITECTURE.md
P3  06_PAGE_SPECS/*.md
P4  08_TASKS/CURRENT_TASK.md
P5  聊天记录
P6  AI 自己的假设              最低优先级
```

执行任何任务前：理解 Context → 判断 Scope → 检查 Constraints → 执行 → Review → 更新 09_CHANGELOG.md。
原则：Preserve before improve / Local before global / Explicit before assumptions /
Simplicity before decoration / Consistency before novelty / 不创造需求 / 不偷偷扩范围 /
发现架构冲突必须明说 / 每次重要修改可解释原因。

## 技术边界

- 纯前端静态站（React + Vite + Tailwind），无后端、无数据库、无实时行情；
- 运行时依赖仅 react + react-dom——**零依赖倾向是工程红线**；
- 内容与代码分离：内容只在 `src/data/domains/`；
- 版本用 website_version_manager 留快照，可回滚。
