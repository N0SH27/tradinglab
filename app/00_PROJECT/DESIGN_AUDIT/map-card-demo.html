产业地图节点卡片 · 三方案试稿

同一节点（算力芯片 · 当前线上数据）的三种减法 · 只动信息架构、不动数据本身 · 追加块按周自动解析
目标：卡片默认高度可控、三秒读完当下，历史一次点击可达
现状

算力芯片

方案 A
两层式 · 论断 + 本周动态
默认只呈现两层：核心论断（立论时的判断）＋本周动态（最新一条追加，按日期自动识别）。中间历史收进「研究轨迹」，点击展开。零维护成本——程序按日期自动切片，不需要人工每周写摘要。
方案 B
仪表化 · 四格速览
长文提炼为固定四格：核心判断 / 本周增量 / 风险信号 / 跟踪动作，每格一句。卡片最薄、扫读最快，最有「研究仪表」感。代价：数据层需新增每周一句话摘要字段（人工或随更新流程撰写），长文整体迁入折叠层。
方案 C
时间线抽屉 · 论断优先
默认只有核心论断一段，所有追加收进「研究轨迹 N 条」抽屉，展开后是带日期的竖向时间线（可滚动）。卡片高度最恒定、最忠实原数据（无提炼、无改写），考古式阅读。
推荐

主推 方案 A（两层式），备选 方案 C。A 与 C 都不动数据、零维护；A 的「本周动态」默认上浮，符合本站点「观察变化」的定位——读者每回来看到的都是「判断 + 这周变了什么」，历史一次点击可达。B 的信息效率最高，但引入每周写摘要的流程负担，若你愿意把它并入周度更新流程，B 可升级为主方案。C 最保守，适合「先解决臃肿、再谈呈现」的两步走。

三个方案共通：生命周期 / 分析重点并入两列字段行；阴阳状态保持大字；关联环节与关联命题（未画出）维持现状不变。
