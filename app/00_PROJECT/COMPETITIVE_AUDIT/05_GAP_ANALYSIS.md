# 05 · GAP ANALYSIS

> 审计日期：2026-09-24 ｜ 方法（任务书 §12）：竞品能力 → 为什么有效 → TradingLabb 现状 → 真实缺口 → 是否战略性 → 是否该补。
> 结论先行：**不是所有竞品优势都值得补**——ARK 的团队规模、MacroMicro 的数据量级、Farnam Street 的受众广度，都不是 TradingLabb 的 Gap。

---

## 一、逐条 Gap 分析（按战略重要性排序）

### GAP-1：Return Loop / Distribution（回访与分发）

- **竞品能力**：Stratechery（邮件+周报+播客矩阵）、Farnam Street（每周 5 分钟邮件）、The Diff（日报节奏）都把「回访」做成产品默认行为。
- **为什么有效**：作者型研究的资产随「重复曝光」复利；没有触达通道，archive 再好也只服务已经记住网址的人。The Diff 的 Byrne Hobart 直白说过：读者的时间机会成本远高于订阅费——**注意力必须先被礼貌地反复请求**。
- **TradingLabb 现状**：纯网站、无订阅、无 RSS、无推送；NOW 页是占位；analytics 只有 trackPageView。
- **真实缺口**：**战略性、且是当前最大缺口**。修正史资产需要「每次修正=一次回访理由」的通道，现在每次账本入账对读者不可见（只有访问首页的人能看到 What Changed）。
- **是否该补**：**是，P0**。但形式必须是 TradingLabb 的：不是 newsletter 内容流，而是「**变化通告**」——每次 Ledger 入账/新研报/裁决书的极简通知。低承诺（Farnam Street 的 5 分钟纪律）、高信号（The Diff 的密度纪律）、零营销（本站品牌纪律）。

### GAP-2：作者身份层（Author Identity / Trust Structure）

- **竞品能力**：Stratechery 的公开 Ethics Policy（不持仓、订阅费占收入主体、自付差旅）；The Diff 的履历+读者画像；Farnam Street 的畅销书+媒体墙。
- **为什么有效**：研究产品的信任=身份×激励结构×时间。匿名/半匿名的高质量内容只能赢得「内容信任」，赢不了「人格信任」，而后者才是订阅与转发的动力。
- **TradingLabb 现状**：「by HSN」只有签名；免责声一句「个人研究笔记」；无履历、无方法论外的人生锚点、无激励结构声明。宣言页回答「我如何理解世界」，不回答「我是谁、我为什么有资格、我靠什么吃饭」。
- **真实缺口**：**战略性**。注意：这不等于要做传统 About 页——可以极克制（一段履历 + 一句激励声明 + 立场声明：无资管业务、无持仓披露义务、不荐股）。「无为」哲学恰好支持极简身份层：不表演、只陈列。
- **是否该补**：**是，P0**——因为 GAP-1 的分发一旦建立，新访客的第一落点问题就是「你是谁」。

### GAP-3：世界模型与命题库不同构（Map Coverage）

- **竞品能力**：ARK 的世界模型（颠覆式创新）与其全部策略产品完全同构；MacroMicro 的行业覆盖以指数组织。
- **为什么有效**：世界模型的价值=它能解释多少你的判断。模型覆盖面小于判断覆盖面时，模型会退化为装饰。
- **TradingLabb 现状**：地图只有 AI 算力产业链一条链（~20 节点）；命题库已覆盖算力/AI 应用/机器人/新能源/光模块/存储/稀土/创新药八条；创新药、稀土、新能源在地图上**无坐标**。
- **真实缺口**：**战略性，但解法不一定是扩地图**。两个选项：(a) 把地图扩成多链；(b) 承认地图=「算力链专用模型」，让命题页自己承担坐标功能。考虑到「地图不是名单，是一组相互等待的 S 曲线」的设计哲学，**(a) 违背该哲学**（多链并列会变成名单）。倾向 (b)：地图保持单一深链，命题页补「坐标段」。
- **是否该补**：**部分，P1**。先小步：非算力命题在单命题页增加「周期位置/估值位置」坐标行（纯文本），不新增页面/导航。

### GAP-4：NOW 页（当下聚合）

- **竞品能力**：TradingView 首屏「一屏看全球状态」的意图（反面样本的正向点）；MacroMicro 仪表盘。
- **为什么有效**：回访用户的第一需求是「这周/现在有什么变化」，不是重读宣言。
- **TradingLabb 现状**：NOW=首页，首页是门面（宣言→研究→变化），不是状态板；账本/日志数据都在，只是没有「近 7/30 天变化」的聚合视图。
- **真实缺口**：**战略性中等**。数据层已支持（latestChanges 派生逻辑现成），是纯产品化缺口。
- **是否该补**：**是，P1**。注意设计纪律：NOW 是「观察层」不是「行情层」——放修正、新证据、裁决，不放报价。

### GAP-5：内容入口的低承诺设计（Accessibility）

- **竞品能力**：Farnam Street 首屏承诺「5 分钟/周」；Stratechery 免费周刊。
- **为什么有效**：深度资产需要低摩擦入口配对；首屏承诺过重会把「现在没时间的人」永远推走。
- **TradingLabb 现状**：首屏是 8rem 大字哲学宣言+四行小字；进入研究需要滚过整屏。
- **真实缺口**：存在但**非战略性错误**——这是品牌选择（重承诺筛选读者），Farnam 是轻承诺扩大读者。两者战略不同。TradingLabb 已选择前者，问题只在**没有给轻承诺读者任何备选入口**（与 GAP-1 同根）。
- **是否该补**：随 GAP-1 一起解（变化通告本身就是低承诺入口），不单独立项。

### GAP-6：英语层 / 全球可读性

- **竞品能力**：全部 benchmark 均为英语产品，分发全球市场。
- **TradingLabb 现状**：全中文（导航有英文标签，内容全中文）。
- **真实缺口**：真实但**当前不应补**。HSN 的认知资产建立在中文语料与 A 股语境上；双语化会双倍维护成本、稀释判断密度。
- **是否该补**：**DEFER**。触发条件：中文 Return Loop 跑通 6 个月且有余力。

### GAP-7：可视化与音频

- **竞品能力**：MacroMicro 图表即产品；Stratechery/Oaktree 每篇配音频。
- **TradingLabb 现状**：水墨/阴阳视觉独特但信息密度低；无音频。
- **真实缺口**：弱。可视化对本站是美学不是信息载体（设计哲学如此）；音频对中文长文有真实价值但属增量。
- **是否该补**：**DEFER**（音频 P2 候选）。

## 二、KEEP / FIX / REDUCE / BUILD / DEFER 分类

### KEEP（已具备，继续强化）

| 项 | 依据 |
| --- | --- |
| 命题七层结构 + 证伪条件预先登记 | 04 矩阵：Thesis 维度「领先（个人尺度）」，全球作者型产品无同等机制 |
| Ledger append-only 修正账本 + 三处投影 | 04 矩阵：Revision 维度领先；首页 What Changed/日志/单命题页 |
| 方法页的方法论 + 日志中的执行证据 | 方法不止写了，而且每周在跑（36/37 周消化批、裁决书）——「被执行的方法论」是多数内容产品没有的 |
| 无为板块（止损/情绪/生活 OS） | 竞品全部谈「做什么」，只有本站系统谈「不做什么」——独特性真实 |
| Research progressive disclosure（研报卡→报告→命题→地图） | 01 文件 §E：30 秒/5 分钟/深潜三级成立 |
| 品牌纪律（零营销、无广告、免责声明、视觉克制） | 与 Stratechery 伦理结构同向，应书面化为激励声明（见 FIX-2） |

### FIX（资产在，表达/产品化有问题）

| 编号 | 问题 | 动作方向（审计建议，非实施） |
| --- | --- | --- |
| FIX-1 | 框架/系统两页内部行话密度高（SSOT、授权、接口、Delta），陌生用户读感=内部说明书 | 降低术语密度，把抽象链落到具体命题的实例走查（用一条真实命题走一遍 WORLD→REVISION） |
| FIX-2 | 信任结构未书面化：无激励声明（不靠此赚钱/无资管业务/不推荐个股），免责声明只有合规句 | 增加极简 Ethics/立场声明（学 Stratechery 的制度化，篇幅控制在一段） |
| FIX-3 | 旧版首页截图等历史资产与现版不一致（截图目录残留 V2-C.1 前结构） | 低优先，但评审展示物料时注意版本 |

### REDUCE（过重，降低公开复杂度）

| 编号 | 问题 | 动作方向 |
| --- | --- | --- |
| REDUCE-1 | System 页的仓位百分比/触发器/If-Then 全文公开，存在被照搬与误读风险 | 不是删除，而是**从「参数公开」转向「配方公开」**：保留状态机逻辑与原则，把具体数值标注为「示例参数，随账户性质而变」；强调「配方无高下，期望为正即可」已在文本中，可前置 |
| REDUCE-2 | 导航 HSN 组只有「宣言」一页，组内单页造成结构冗余 | 身份层（FIX-2 落地物）建成后自然解决；不为其单独改导航 |

### BUILD（真实战略缺口，需要建设）

| 编号 | 缺口 | 优先级 |
| --- | --- | --- |
| BUILD-1 | Return Loop：变化通告机制（新账本入账/新研报/裁决书的极简通知；形式待定：邮件/RSS/推送，原则：低承诺高信号零营销） | **P0** |
| BUILD-2 | 作者身份层（极简 About：履历锚点+激励声明+立场） | **P0** |
| BUILD-3 | NOW 聚合页（近 30 天变化：账本+新证据+裁决；观察层非行情层） | P1 |
| BUILD-4 | 非算力命题的坐标化（单命题页增加周期/估值位置段，纯文本，先不碰地图） | P1 |

### DEFER（理论有价值，当前不做）

| 项 | 触发条件 |
| --- | --- |
| 英语层 | 中文 Return Loop 跑通 ≥6 个月且有余力 |
| 音频化 | BUILD-1 后评估 |
| 商业化/订阅 | 有真实受众后再谈；当前无利益冲突本身是信任资产（Stratechery 教训：先独立后变现） |
| 地图多链化 | 违背「地图不是名单」哲学，除非找到多链的 S 曲线统一表达 |
| 数据接入/实时指标 | 与「人工选择什么值得观察」宣言冲突，明确不做 |
| 社区/评论 | 引入共识噪声，与「价格是共识」的观察立场冲突；至少当前不做 |

## 三、反向审计（任务书 §20）

逐条问：不做这些建议，TradingLabb 是否仍成立？

- 不做 BUILD-1（分发）：**仍「成立」但资产无法复利**——修正史只在被记得网址的人面前增长。判定：**YES 成立 / 但战略上等于放弃复利**。这是「不是生死问题、但是方向问题」的典型案例。
- 不做 BUILD-2（身份层）：**成立**——内容信任可独立存在。但分发建立后新访客转化会系统性漏损。判定：**半战略性**。
- 不做 BUILD-3/4：成立。P1 而非 P0 的原因即在此。
- 不做 REDUCE-1：成立，但风险敞口（被误读为收益承诺）与免责声明矛盾。判定：**应做，成本低**。

**结论：唯一「不做则复利不成立」的是 BUILD-1。** 其余都是增强项——这符合任务书「禁止为了竞品增加功能」的纪律。
