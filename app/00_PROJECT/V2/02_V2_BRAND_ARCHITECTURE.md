# V2-02 · BRAND ARCHITECTURE — 品牌架构（最终版）

> **V2-01 定稿（2026-08-23）。** 本文件是 TradingLabb V2 品牌架构的唯一事实源。
> 设计层文档。与 P0/P1/P2 冲突时以 P0/P1/P2 为准，冲突记入 06_V2_IMPLEMENTATION_LOG.md。

## 1. Brand Definition（品牌定义）

**TRADINGLABB — A Personal Investment Intelligence Lab.**

中文内部定义：

> **一个观察变化、形成命题、修正认知的个人投资研究实验室。**

TradingLabb 的核心产品不是文章，不是观点，而是：

> **Research Process + Intellectual Record（研究过程 + 认知档案）**

它回答的长期问题是：**10 年以后，TradingLabb 是什么？**——
一个持续累积、可版本化、可追踪、可修正、可复用的个人认知数据库。

## 2. Brand Positioning（品牌定位）

TradingLabb **不是**：

- ❌ 财经媒体
- ❌ 投资教育平台（教育是副产品：不教答案，展示思考过程）
- ❌ 股票推荐网站
- ❌ KOL 内容站
- ❌ 个人博客
- ❌ "个人版 ARK"

与 ARK 的边界：ARK 是 Research → Investment Product，核心资产是 AUM；
TradingLabb 是 Observation → Thesis → Revision → Knowledge，核心资产是 **Intellectual Capital**。

商业化暂不作为 V2 核心：不定位课程平台、付费社群、会员制、荐股服务、Newsletter 商业产品。
先积累认知资产密度（长期目标：20+ Thesis / 50+ Revision / 100+ Observation），再讨论商业化。

## 3. HSN Role（人的角色）

**HSN = Founder · Observer · Researcher。**

不是 Investor / Trader / Analyst / Expert。

理由：这个品牌要经营 5–10 年。"HSN 如何判断世界"比"HSN 推荐什么股票"品牌寿命大得多，
且不被"股票投资"标签锁死——可以讨论科技、产业、资本、商业、人、周期、社会变化。

HSN 的核心不是"告诉别人买什么"，而是：

> **公开展示自己如何理解世界、形成判断并修正判断。**

品牌关系：**TradingLabb 是品牌，HSN 是人。** 品牌长期存在，个人才是 IP。
署名方向（克制）：`TradingLabb by HSN` / `HSN / TradingLabb`；思想先于履历，不做简历式自我介绍。

## 4. Brand Architecture（三级品牌结构）

```text
                    HSN
                     │
              Founder / Observer
                     │
                     ▼
                TRADINGLABB
                     │
       ┌─────────────┼─────────────┐
       ↓             ↓             ↓
     WORLD         CAPITAL         LIFE
```

| 世界 | 回答 | 包含 |
|---|---|---|
| **WORLD** | 世界正在发生什么？ | MAP · CYCLE · DIMENSIONS · SIGNALS/NOW |
| **CAPITAL** | 这些变化如何进入资本与投资判断？ | THESIS · SYSTEM · FRAMEWORK · JOURNAL · ESSAYS |
| **LIFE** | 人在不确定性中如何行动与克制？ | WUWEI · DISCIPLINE · LIFE OS |

这个结构解释了为什么一个投资网站里会有 WUWEI——
不是"东方哲学化"，而是因为 **投资最终是一个人的决策系统**。

## 5. Core Worldview（核心世界观）

沿用 P0 产品哲学六条（不变）：

1. 观察变化，而非预测未来；
2. 阴阳世界观：阳 = 看得见的增长与叙事；阴 = 看不见的约束与出清；
3. 反者道之动：所有趋势的尽头都是反转；
4. 不操作是持仓：无为、空仓、等待是系统的组成部分；
5. 做赌场不做赌徒：玩的不是行情，是统计；
6. Build once, systematize everything。

**东方哲学必须现代化转译，不为"中国风"而使用传统符号：**

| 概念 | 不做 | 而做 |
|---|---|---|
| 阴阳 | 画 ☯️ 装饰 | Growth/Constraint · Narrative/Reality · Expansion/Contraction |
| 无为 | 写"道家" | **No position is also a position.** |
| 反者道之动 | 放老子名言装饰 | **Every trend contains the conditions of its reversal.** |

尤其避免：大量古典纹样、书法堆砌、禅意装饰、传统文化展示式设计、过度使用阴阳图形。
**唯一保留的东方具象符号是 Polarity Instrument（阴阳仪），且受第 7 节数量与动效硬约束。**

## 6. TradingLabb Loop（操作循环）

```text
OBSERVE
   ↓
MAP
   ↓
THINK
   ↓
THESIS
   ↓
ACT / DON'T ACT
   ↓
REVISE
   ↓
ARCHIVE
   ↓
OBSERVE AGAIN
```

| 动作 | 回答 | 产品落点 |
|---|---|---|
| OBSERVE | 发生了什么？ | NOW / SIGNALS |
| MAP | 它发生在哪里？与什么连接？ | WORLD MAP |
| THINK | 如何解释？ | SYSTEM / FRAMEWORK |
| THESIS | 当前相信什么？ | LIVE THESIS |
| ACT / DON'T ACT | 是否采取行动？ | （WUWEI 是其行为原则） |
| REVISE | 什么证据改变了判断？ | JOURNAL |
| ARCHIVE | 留下可追溯的认知记录 | 知识归档树 |

注：不再单独使用 UNDERSTAND——**MAP 本身就是 Understand**。
WUWEI 不是普通功能，是 ACT / DON'T ACT 背后的行为原则。

## 7. Polarity System（阴阳仪的品牌定位）

**TradingLabb Polarity / Polarity Instrument / 阴阳仪**——品牌底层认知符号，
属于 **TRADINGLABB CORE WORLDVIEW**，不属于 WORLD / CAPITAL / LIFE 任何子栏目。

禁止描述为装饰性"太极图"；它是**认知仪器（认知仪表盘）**，不是传统文化装饰。

三态：**YANG**（Growth / Adoption / Expansion）、
**TURN**（Transition / Reversal / Inflection）、
**YIN**（Constraint / Clearing / Contraction）。
核心循环：`YIN → TURN → YANG → TURN → YIN`，与 `MapNode.state` 数据结构天然一致。

**用户裁决（2026-08-23，硬约束）：**

- 全站阴阳图形 **至多 2 个**：现有 1 个（Cycle 页 `Taiji` 组件）保留；
  至多再新增 1 个（首页 POLARITY 章节的 Polarity Instrument），不得再有第三个；
- 新增阴阳仪 **默认完全静止**，仅在 hover / click 时才产生运动（保守方案）；
- 视觉禁令不变：无粒子、辉光、3D、阴影、WebGL、纹理；`prefers-reduced-motion` 下零运动。

详细规格见 05_V2_POLARITY_SYSTEM.md。

## 8. Content Architecture（内容架构）

五类核心内容，所有内容优先落入这五个桶：

| 类型 | 回答 | 频率 |
|---|---|---|
| OBSERVATION | 我看到了什么变化？ | 高频、短 |
| THESIS | 我因此相信什么？ | 中长篇 |
| MAP | 它与其他产业、技术、资本什么关系？ | 图形化 |
| REVISION | 什么证据让我改变判断？ | 事件驱动 |
| ESSAY | 我对一个长期问题的系统思考 | 低频高价值 |

内容飞轮：`OBSERVATION → THESIS → MAP → REVISION → ESSAY → OBSERVATION`。

## 9. Personal IP Strategy（个人 IP 策略）

个人 IP 建立为 **"HSN 如何判断世界"**，而非"HSN 推荐什么股票"。
路线是 Founder-as-Researcher，不是 Influencer-as-Trader。

个人签名（长期核心句）：

> **Observe change. Update beliefs.**
> **观察变化，修正认知。**

建议性长期栏目（内容策略定义，不实现功能）：

**WHAT I BELIEVE NOW**——每月 1 次，只回答：

```text
3 things I'm more confident about.
2 things I'm less confident about.
1 thing I changed my mind about.
```

同时强化 HSN / Thesis / Revision / Probability / Wuwei / 长期主义，天然可同步外部平台。

## 10. Distribution Strategy（分发策略）

TradingLabb 是 **Master Content / Canonical Archive**；外部平台只是 **Distribution Layer**
（X / 微信公众号 / 知乎 / 小红书 / 视频 / Newsletter 等）。

```text
External Platform → Discovery / Distribution → TradingLabb → Permanent Archive
```

- 外部平台负责获客，TradingLabb 负责沉淀；
- **禁止让外部平台成为认知资产的唯一存储位置**；
- 当前不做 Newsletter、不日更、不追热点——认知数据库深度优先。

## 11. Brand Voice（品牌语调）

沿用 P0 品牌人格并加固：

克制、诚实、耐心、可证伪、允许犯错、允许修正、不扮演权威、展示过程而非结果。

- 短句、断言式、不讨好（"没有系统支撑的重仓，不叫勇气，叫扶贫"）；
- 对错误坦然；书卷气；避免互联网营销腔、空泛形容词；
- 所有定义必须能指导产品设计与内容生产，不写无法执行的口号。

## 12. Forbidden Positioning（禁止定位汇总）

- ❌ KOL / Stock Picker / Trading Guru / Investment Expert / Financial Influencer / Analyst Persona
- ❌ 财经媒体 / 投资教育平台 / 荐股网站 / 个人版 ARK
- ❌ 课程 / 付费社群 / 会员制 / Newsletter 商业产品（V2 阶段）
- ❌ "太极图"式装饰语言、中国风堆砌、禅意装饰
- ❌ 专家人设——人格的反面是不扮演权威，展示过程

## 13. Long-term Moat（长期护城河）

核心资产优先级排序：

1. **THESIS**
2. **REVISION HISTORY**
3. **WORLD MAP**
4. **JOURNAL**
5. **ESSAYS**

理由：文章可以被复制；一个持续 5 年记录的
"观点 → 证据 → 概率 → 修正"数据库很难复制。这才是真正的 **Intellectual Moat**。

时间维度：一年后 Journal 是资产，三年后是信誉，五年后本身就是投资履历。
