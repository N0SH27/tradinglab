## 02 · Content Translation Rules（B-0 · 总规则）

本轮起草全程使用的规则（沿用 V2-30 §16，本包执行实例见 §09 矩阵）：

| 规则 | 内容 |
|---|---|
| 五操作封闭集 | KEEP / COMPRESS / REMOVE / MOVE / REWRITE——REMOVE 只删重复投影，不删 Canonical Content |
| 信息价值五问 | 无价值→删；有价值但重复→合并；有价值但位置错→MOVE；有价值但表达难→REWRITE；有价值且位置对→KEEP |
| 表里分离 | 页面结构固定（认知导航），表面语言自然；WHAT/WHY/SO WHAT/BUT 是内部结构，永不作为页面标题 |
| 表里语言三层 | Architecture Language（内部保留）/ Reader-facing Language（用户看到）/ Brand Language（NOW/WORLD/THESIS/JOURNAL/POLARITY 白名单） |
| 事实不可动 | 不改数字、事实、时间、因果、结论强弱；不加新证据、新判断；可改的只有表达方式 |
| SO WHAT 审核 | 每段问「所以呢？」——答不上来：压缩 → 移到 Deep Dive → 删除 |
| 反营销 | 禁止惊人/王炸/重磅/必然/确定性机会/强烈推荐等；保持 Observation / Analysis / Judgment / Risk（Observer ≠ Stock Picker） |
| 视觉多样性 ≠ 信息多样性 | 阅读动作可以丰富，但每种动作不得承载一个新信息对象；交互必须回答「这让用户理解了什么」 |

## 03 · Homepage Final Experience Proposal

### 3.1 五场景形态约束（给 V2-C 的硬约束，HDG-1 已裁决方向）

> **Human Final Decision 修正 ①（2026-09-04 · LOCK）：五场景是设计师和 AI 的「骨架」，不是用户看到的「目录」。首页 = 一条连续的认知旅程，不是五个章节——用户界面上不得出现 ENTRY / NOW / SEE / THINK / CHANGE 的场景标签或幕间分隔标题；场景之间靠阅读行为的切换来区分，不靠标题与分割线宣告。**（与 OQ-4 裁决一致：场景名为 Internal Cognitive Scene Names。）

```text
ENTRY    静 · 整屏只有一句                 —— 建立气质
NOW      Flip · 三张阅读卡                 —— 表面 → 隐藏变量
SEE      Rotate → Explore · 仪器 + 地图    —— 用 Polarity 看世界
THINK    Read → Reveal · 信念 + 研究       —— HSN 得出了什么
CHANGE   Compare · 一张对比卡              —— 我会错，我会改
WUWEI    静 · 静默尾章（OQ-1 裁决）
END      静 · 终幕（现状保留）
```

**反 Section Stack 判据（F-30-1 落地 + Human 修正①强化）：** 五场景的垂直节奏、留白量、网格宽度**必须不同**——ENTRY/END 是整屏呼吸；NOW 是卡片排；SEE 是仪器+画布的组合体（允许打破 max-w 网格成为全页最「开」的一幕）；THINK 回到阅读宽度；CHANGE 是单卡。若 V2-C 产出五个等高 `hairline-t` 矩形块、或以场景名做章节标题，验收不合格。**交互集合封闭：不得再增加任何新交互（Human Final Decision 明令）。**

### 3.2 信息量预算（LOCK 建议）

| 场景 | 信息上限 | 动作 |
|---|---|---|
| ENTRY | 1 品牌 + 1 句 + 1 入口 | Read |
| NOW | 3 卡 ×（正面 2 行 + 背面 3 行） | Flip |
| SEE | ≤7 节点 + 3 态 | Rotate / Explore |
| THINK | 1 信念 + 1 研究卡 | Read / Reveal |
| CHANGE | 1 张 THEN/NOW/WHY 卡 | Compare |
| WUWEI + END | 现状压缩保留 | 静 |

## 05 · Research Translation Proposal（B-7～B-9 总则）

### 5.1 三层职责（LOCK 候选重申）


### 5.2 30 SEC 翻译总则（四格不重造，只做语言翻译）

四格标签的内部名统一为 **THE QUESTION / THE FINDING / WHY IT MATTERS / WHAT COULD CHANGE THIS VIEW**；读者可见文案用自然语言小标题（候选：「这篇研究在问什么 / 目前看到什么 / 为什么值得在意 / 什么会让我重新研究」——最终措辞 Human 定稿）。第三格统一从「对已有判断的影响」（作者视角）转向「为什么值得在意」（读者视角）；第四格保留触发语义。

### 5.3 5 MIN 写作纪律（已执行于 §06 草稿）

- 每份 3～4 个 Key Findings；每条内部完成 WHAT/WHY/SO WHAT/BUT，页面呈现为自然语言段落，**禁止出现四个结构词作为标题**；
- 30 SEC ≠ 摘要复制；5 MIN ≠ 30 SEC 扩写；Deep Dive ≠ 前两层重复；
- 每个 Key Finding 末尾给出「溯源自检」（来自报告哪一节），供 Human 核对「未改变事实」；
- SO WHAT 审核已逐条执行（§06 每条附「所以呢？」自检）。

### 5.4 Human Final Decision 强化（2026-09-04 · LOCK）

> **B-8 · PASS WITH STRONG EMPHASIS：5 MIN 不是附属层，是 TradingLabb Research 的核心产品层 / 传播层。** 30 SEC 让人愿意进来，Deep Dive 让人确认可信，**5 MIN 让人真正理解并带走**。它必须成为全文质量标准最高的一层——不是「摘要的扩写」，而是独立写作成果。新增第二硬标准：除「不改变事实」（已有溯源自检）外，每条 Key Finding 必须通过**「可复述性」检验**——一个不了解 TradingLabb 的读者读完 5 MIN，能不能在不碰全文的情况下，向别人复述这篇报告的核心论证？不能复述 = 不合格。
>
> **B-9 · PASS WITH MODIFY：标题走向「问题式」，但不机械套用「谁 / 为什么 / 什么」模板。** 目标是让标题**像一个研究者真正在问的问题**，而不是 SEO 生成器的产物。§06 的 12 个候选按此标准视为定稿基准——保留自然语感，允许陈述式变体（如「这改变了我的判断吗？——没有，但它垫厚了地基」），V2-C 排版时不得为凑「问题感」而注水。

剪刀差（意志能否兑现为能力的尺子）/ 火车头（云厂商资本开支的措辞）/ 咽喉（封装产能与设备交期）/ 电力（最终约束）/ 偿还者（应用层收入缺口）。这条链的全部复杂性，最后收敛为一个问题：**意志能否兑现为能力——而它只能用供给端的事实回答，不能用需求端的叙事回答。**

### REPORT #2 · 存储周期：价格上涨失效的周期解剖

#### 30 SEC（语言翻译稿）

| 格 | 翻译稿 |
|---|---|
| THE QUESTION | **一个产业的价格上涨，从什么时候开始失效？**——更根本地：结构性短缺和周期性短缺，能不能在事中区分，而不是事后？（KEEP 原句） |
| THE FINDING | 失效不从价格本身开始。它沿一个次序逐级蔓延：**先是股价不跟，然后买方降级硬件方案，然后龙头的损益表开始承压**——价格，是最后才动的那一级齿轮。 |
| WHY IT MATTERS | 如果这次序成立，「价格还在涨」就不是周期的反证，而是周期运转到特定档位的特征。**等价格转向才确认周期的人，等的是最后一级。** |
| WHAT COULD CHANGE THIS VIEW | 如果三星、海力士的盈利预测不降反升，周期判据失效。（另有四条，见全文。） |

#### 5 MIN · Key Findings 草稿（4 条）

**KF-1 · 失效有一个次序，而它已经走完两级半。**
第一级：涨价新闻和股价表现开始背离（已发生）。第二级：买方不再用「停止采购」回应涨价，而是直接降级硬件方案——下一代 AI 服务器的 HBM 从 12 层降到 8 层（已发生）。第二级半：全球最大买方把下季度毛利率指引下调，明确归因存储定价（半发生）。价格本身回落？还没发生。
**但：** 降配有一个反直觉的回声——层数降低提高封装良率，同等产能下有效供给反而增加。买方的一个动作同时压缩需求、放松供给：**周期判据没被证伪，但被拉长了。**
（溯源：§01 / §04 反证并存机制 · 所以呢？→ 给出「现在走到哪了」的可观察坐标。）

**KF-2 · 存储不是一个生意，是两个。**
HBM 是成长期的产能分配生意（结构性短缺，量价齐升）；通用存储是成熟期的周期生意（价格 × 产量双击）。两者共用「存储」之名，混用它们是存储研究最常见的认知事故。估值参照系已经分裂：三星、海力士 5 倍 PE，市场已在定价 2028 年利润腰斩；而长鑫以约 30 倍 PE 上市。
**但：** 两种生意在原厂的财报里合并列示，外部观察者无法分离——「HBM 的阿尔法对冲通用存储的贝塔」这一反证，在证据结构上既无法证实也无法证伪。这是本研究最大的观测黑洞。
（溯源：§2.3 / §05 估值参照系 / §06 · 所以呢？→ 防止读者用一套逻辑读错两个环节。）

**KF-3 · 第四玩家改写了周期的参数，而不是方向。**
长鑫的产能路径（18 → 50 万片/月，2025→2028）让 DRAM 从三家寡头回到四玩家。影响不在供给量本身，而在**减产纪律的瓦解概率**——三寡头的默契在四人博弈里不再稳定。周期的机器不变，转速被改写：低谷可能更长，复苏的斜率可能更缓。
**但：** 如果长鑫爬坡停滞，或四玩家形成新的减产默契，这个变量失效，下行段长度回归旧参数。
（溯源：§01 / §04 / §08 第四条 · 所以呢？→ 修正「周期什么时候完」的时间预期。）

**KF-4 · 碳酸锂把整条路完整走过一遍。**
碳酸锂前鉴：价格 30 万时股价见顶，60 万时股价不跟，跌到 5.8 万时市值蒸发九成。逐阶段对照，存储当前处于阶段三与阶段四之间——而阶段四（买方方案降级）在碳酸锂前鉴中根本没有对应物：AI 硬件的买方集中、理性、有方案弹性，响应速度比碳酸锂的下游快。这不是类比断裂，是存储周期贡献的新观察。
**但：** 类比是工具，不是因果——如果 AI 资本开支持续超预期、HBM 短缺被证实为结构性，这条时间轴在 HBM 分支上作废（通用存储分支不受影响）。
（溯源：§05 / §08 第二条 · 所以呢？→ 给出位置判定及其失效边界。）

### REPORT #3 · 电力约束：从判断到可跟踪结构

#### 30 SEC（语言翻译稿）

| 格 | 翻译稿 |
|---|---|
| THE QUESTION | **「算力的尽头是电力」——这句话怎么从一句判断，变成一把可以跟踪的尺子？**（KEEP 原意，语言自然化） |
| THE FINDING | 约束的硬度不来自叙事，来自三个可度量机制的汇合：**电网临界点已被主要经济体普遍越过；电力指标成为智算中心选址的第一权重；容量电价把约束变成了钱。** |
| WHY IT MATTERS | 电力是整条算力链中唯一「估值出清」的环节——它的定价最不需要叙事配合，逻辑最硬，理解者最少。**谁先把约束变成可跟踪的指标，谁就拥有这个环节上稀缺的定价锚。** |
| WHAT COULD CHANGE THIS VIEW | 如果智算中心选址中电力指标的权重下降，约束硬度的判据失效。（另有三条，见全文；七项指标中至少两条建立持续数据流后，全篇整体重审。） |

#### 5 MIN · Key Findings 草稿（3 条）

**KF-1 · 约束是结构性的，因为它来自三个永远不会相等的速度。**
电力系统的稳定结构是三侧：负荷侧（数据中心）以 AI 资本开支的速度增长，电网以基建的速度增长，发电侧以能源转型的速度增长。约束不来自任何一侧的绝对水平，而来自三侧速率之差——**缺口是结构的，不是暂时的。** 主要经济体的风光发电占比已全部越过约 10% 的电网调度临界点（中国 21.8%、欧盟 24.6%、美国约 20%），储能从「补充」变成「刚需」。
**但：** 约束有它的松弛变量——金刚石散热的实测数据（每瓦算力提升 20%+）意味着约束的硬度不是常数。跟踪约束，必须同时跟踪它的松弛项。
（溯源：§2.1 / §01 / §04 · 所以呢？→ 回答「这个约束是真的还是一阵风」。）

**KF-2 · 反身性最弱，是这个环节最值钱的性质。**
链条两端构成镜像：叙事最密集处（存储）反身性最强，叙事最稀薄处（电力）反身性最弱。电力环节的估值出清，正是叙事稀薄的定价痕迹——**这个环节的价格不需要新叙事来维持。** 而电价机制改革（容量电价 13 省、欧洲讨论灵活性电价）决定约束何时从物理事实变成财务报表事实。
**但：** 如果电力环节的估值重新拥挤而产业逻辑未变，说明此前的「出清」只是筹码现象而非结构——反身性判断需要重审。
（溯源：§2.2 / §2.3 / §08 第四条 · 所以呢？→ 回答「为什么这个环节和别人不一样」。）

**KF-3 · 本研究最重要的产出，是一张缺口地图。**
七个候选跟踪指标（选址权重 / 风光占比 / 容量电价 / 大储装机 / 负电价时长 / 每瓦算力 / IDC 回报分化），**五个只有快照、两个证据不足，没有一个具备持续数据流。** 这张缺口地图把「电力很重要」的叙事，转换成了「要跟踪电力，需要建立哪七条数据流」的结构清单。因此本报告只产出一份命题候选规格，并立下进入条件：**至少两项指标建立持续数据流之前，它只是规格，永远不是命题。**

### REPORT #4 · 商保支付端：从政策推演到目录落地

#### 30 SEC（语言翻译稿）

| 格 | 翻译稿 |
|---|---|
| THE QUESTION | **2025 年初写下的商保支付端推演，到目录正式落地为止，哪些命中、哪些偏离、偏差的结构是什么？**——以及：支付结构的变化，如何改变创新药的估值逻辑。（KEEP 原句） |
| THE FINDING | 推演的**方向全部命中，路径有系统性偏差**：政策没有走「地方先行」，而是国家层面直接同步推出双目录。最深层的变化不是目录本身，而是定价机制——**医保从「指导定价」退为「给出支付标准」，企业恢复自主定价权。定价权的修复，先于支付量的修复。** |
| WHY IT MATTERS | 如果国内支付端完成从单一医保到「医保 + 商保」的双层切换，创新药的估值逻辑将从「出海期权」变成「双市场现金流」。而且这是一场**可以被逐季度证伪的变革**——它不靠叙事验证，靠目录、赔付率和销售额验证。 |
| WHAT COULD CHANGE THIS VIEW | 2026 年底，目录执行满一年：如果目录内药品的实际报销远低于预期，通道就是「通而不量」，支付变革停留在文件层。（另有三条，见全文。） |

#### 5 MIN · Key Findings 草稿（4 条）

**KF-1 · 八项推演方向全中，但路径有系统性偏差——这比全中更有信息量。**
回测表逐环节对照：8/8 方向命中；两处路径偏差（预判「地方先行」，实际国家同步；时间表高估了提前幅度）；一处当时的存疑标注避免了错误入账；两处证据缺口诚实维持至今。结论：这批推演的可信度上调，但推演来源有一个固定折扣项——**倾向于把「年底」说成「上半年」，消化时按此打折。**
（溯源：§05 回测表 · 所以呢？→ 这份报告首先是 HSN 对自己研究方法的一次回测——可信度与偏差结构同时入档。）

**KF-2 · 最深的变化不是目录，是定价权。**
2025 年之前，医保谈判实质是指导定价；机制切换后，医保给出支付标准，商保叠加支付，企业在差额区间自主定价（例：医保付 4 万、商保报 6 万、企业对高支付能力患者定价 10–20 万）。参照系：同期海外授权定价约为国内的 33 倍——价差就是定价权缺失的量化表达。
**但：机制成立 ≠ 行为发生。** 机制落地半年后，第一个行为层证据偏否定：国内创新药仍贴着医保定价（医保年支出约 2.5 万亿，创新药支付刚超 1000 亿，约 4%）。定价权修复的兑现，要等 2026 年谈判季的真实定价案例。
（溯源：§2.2 / §06 / §05b 第 05 行 · 所以呢？→ 区分「制度文本」与「市场行为」，这是全篇最锋利的观察。）

**KF-3 · 通道已建立，不等于通道已通水。**
8000 亿增量的测算（商保赔付率 30% → 80% 的美国对标）是长期空间，不是首年预期：首年目录以 CAR-T 等高值疗法为主，覆盖窄；执行满半年，目录品种没有公开放量案例——今年最轰动的放量（英克司兰）走的是医保乙类通道，不是商保目录。扩容是行政动作而非制度重建，但放量的证据要等。
**但：** 反方向也要登记——支付端并非全面收缩，而是结构性腾挪：脑机接口这类真正的新技术疗法，医保仍会开口子。
（溯源：§04 / §05b 第 01–02 行 · 所以呢？→ 校准「政策落地 = 业绩落地」的常见误读。）

**KF-4 · 双层结构不等于总支付额扩大——也可能只是支付责任的转移。**
阴面必须并置：2025 年 1–9 月出院人数同比 -5.5%、2026Q1 器械招标同比 -14.36%、上海提高原研药自付比例——商保扩容与医保控费在同时发生。节奏判断因此被强化：在 2026–2028 的卡位期前半段，支付端逻辑仍主要靠出海兑现，而非国内商保。第一个年度分辨率的检验点：**2026 年底，目录执行满一年的报销与销售数据。**
（溯源：§05b / §07 建议 05–07 · 所以呢？→ 防止命题单腿化，给出明确的检验时点。）
