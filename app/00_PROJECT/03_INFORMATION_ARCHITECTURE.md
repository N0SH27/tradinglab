# 03 · INFORMATION ARCHITECTURE — trading-lab

> 网站到底有哪些东西。P2 级。原则：最少页面、最高信息密度、最低认知成本。

---

## Sitemap（现状，11 栏目 + 文章详情）

```text
#/            索引 HOME —— 门面 + 全站缩影（五幕 + 目录 + 终幕）
├── #/manifesto  宣言 —— 世界观总纲
├── #/system     系统 —— 交易系统的四层结构与三要素
├── #/thesis     命题 —— 8 个产业命题（手风琴聚合页）
├── #/essays     文集 —— 6 篇长文列表
│   └── #/essays/:id —— 文章详情（唯一二级页面，返回按钮与滑动手势的唯一落点）
├── #/map        地图 —— 15 节点产业链 + 佩雷斯时代标尺
├── #/cycle      周期 —— 七阶段圆环 + 题材生命周期 + 四面权重
├── #/dimensions 四象 —— 逆时针曲线九宫格
├── #/wuwei      无为 —— 不操作的哲学与 LIFE_OS
├── #/framework  框架 —— 方法论库（知识底座）
└── #/journal    日志 —— 修正记录的时间流
```

页脚：知识归档树（"内容最终沉淀为一棵树，而非时间流"）。

## 模块职责

| 模块 | 解决什么问题 | 优先级 |
|---|---|---|
| 索引 | 3 秒内回答"这是哪、这人怎么想、现在关注什么" | 核心 |
| 命题 | 当前最重要的研究判断（概率+证伪+修正痕迹） | 核心 |
| 地图 | 产业之间的关系与时代位置 | 核心 |
| 文集 | 完整书写的长文（思想的最深形态） | 核心 |
| 日志 | 修正留痕——"研究还活着"的证据 | 核心 |
| 宣言/系统/周期/四象/无为/框架 | 世界观的六个切面 | 辅助 |

## 页面关系（互链）

- 命题 ↔ 地图：双向链接（Thesis.nodes / MapNode.theses 字段）；
- 首页五幕：NOW → WHY → SYSTEM(大命题) → CAPITAL(概率刻度) → NEXT(周期位置)；
- 文集文章 → related 延伸链接到相关栏目；
- 一切最终归档到页脚知识树。

## 用户路径（核心三条）

1. **初访**：索引 →（目录）→ 命题 → 日志（看修正记录建立信任）；
2. **深读**：文集 → 文章详情 →（返回）→ 相关栏目延伸；
3. **研究追踪**：地图 → 节点详情 → 关联命题 → 日志看该命题的修正史。

## 结构纪律

- 一级页面不挂返回按钮；唯一天然层级是 文章详情 → 文集；
- 新栏目上线前必须回答："它沉淀为树的哪一枝？"
- 操作类内容不进站（留在 Notion）。
